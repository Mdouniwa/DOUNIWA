# しゃべるえほん(しゃべる絵本メーカー)

家族専用の「しゃべる絵本メーカー」PWA。子どもがアイコンを5つ選ぶと、AIが物語・挿絵・ナレーション音声を自動生成して絵本にします。iPad(Safari・ホーム画面追加)で読む家庭内PoCです。

- **5歳(つくる側)**: アイコンを5つ選ぶ(選んだ順にお話になる)→ AIが絵本を生成 → 気に入らなければ自分の声で録り直し
- **2歳(よむ側)**: 大きな左右ボタンでページ送り、画像タップで効果音、本をめくるアニメーション
- **親**: ホーム右上隅を**3秒長押し**で親モード(削除・並び替え・表紙変更・よみあげ文編集)

## アーキテクチャの要点

- **絵本の生成(作成フロー)だけ** インターネット接続が必要です。生成済み絵本の閲覧・再生は**完全オフライン**(生成された画像・音声はBlobとしてIndexedDBに保存し、以後はローカルから読み込む)。
- 生成は **Vercelのサーバーレス関数 `/api/generate-book`** 経由でGemini APIを呼びます。**APIキーはサーバー側だけ**に保持し、クライアントには一切露出しません。

## 技術構成

- Vite + React + TypeScript
- IndexedDB(`idb`)— 画像・音声・メタデータを端末内保存
- PWA(`vite-plugin-pwa`)— 生成済み絵本はオフライン完全動作
- 生成: Vercel Serverless Function + Gemini API(`@google/genai`)
- 録音(録り直し): MediaRecorder API(iOSは `audio/mp4`、他は `webm` にフォールバック)
- 読み上げフォールバック: Web Speech API `speechSynthesis`(ja-JP)
- 効果音: WebAudio(OfflineAudioContext)によるコード合成。外部音源ファイルなし

### 使用しているGeminiモデル(環境変数で差し替え可能)

`api/generate-book.ts` の3段階生成。モデルIDは改廃が速いため、すべて環境変数で上書きできます。

| 用途 | 既定モデル | 環境変数 | 選定理由 |
|---|---|---|---|
| 物語生成(JSON) | `gemini-2.5-flash` | `GEMINI_TEXT_MODEL` | 短い日本語の物語+構造化JSON出力に十分で最も安価な汎用Flash |
| 挿絵生成 | `gemini-2.5-flash-image`(Nano Banana) | `GEMINI_IMAGE_MODEL` | 1枚 約$0.039 の安価な画像モデル。※2026-10-02に旧版が廃止予定のため、後継(Nano Banana 2 系)が使えるようになったら環境変数で差し替え推奨 |
| 音声生成(TTS) | `gemini-2.5-flash-preview-tts` | `GEMINI_TTS_MODEL` | Gemini内蔵の安価な日本語対応TTS(約$0.03/分) |
| TTSの声 | `Leda` | `GEMINI_TTS_VOICE` | 優しい声のプリセット |

> 音声はGeminiが**生のPCM**で返すため、サーバー側でWAVヘッダを付けて `audio/wav` にしてから返します(iOS Safariで再生可能にするため)。

### 生成1回あたりの想定コスト概算

6ページ構成の場合(2026年時点の価格・約¥155/$で試算):

- 物語(テキスト): ほぼ無視できる(< ¥1)
- 挿絵: 6枚 × $0.039 ≈ $0.23 ≈ **約¥36**
- 音声: 合計およそ1分 × $0.03 ≈ **約¥5**
- **合計: 1冊あたり おおむね ¥40〜¥55**(当初見積り「40〜50円程度」と整合)

## 開発

```bash
npm install
npm run dev     # フロントエンド開発サーバー(/api はローカルでは動きません。実生成はVercel上で確認)
npm run build   # 型チェック + 本番ビルド(dist/)
```

- サーバーレス関数(`api/`)の型チェック単独実行: `npx tsc --noEmit -p api/tsconfig.json`
- アプリアイコンを変更する場合は `scripts/icon.svg` を編集して `node scripts/generate-icons.mjs`

## Vercelへのデプロイ手順

1. このリポジトリをGitHubにpushしておく
2. [vercel.com](https://vercel.com) にログイン → **Add New… → Project**
3. このリポジトリを **Import**
4. Framework Preset に **Vite** が自動検出されることを確認
   - Build Command: `npm run build` / Output Directory: `dist`
   - `api/` 配下は自動的にサーバーレス関数として認識されます
5. **環境変数を設定**(下記「環境変数の設定手順」参照)
6. **Deploy** を押す
7. 発行された `https://〜.vercel.app` のURLをiPadで開く

以後は対象ブランチにpushするたびに自動で再デプロイされます。HTTPSはVercel標準なのでPWA(Service Worker)もそのまま動きます。

### 環境変数の設定手順(`GEMINI_API_KEY`)※道庭さんご本人の作業

> **このAPIキーの発行・設定は本アプリの実装範囲外**です。以下の手順でご自身で設定してください。

1. **APIキーを取得**: [Google AI Studio](https://aistudio.google.com/apikey) にGoogleアカウントでログインし、「Create API key」でキーを発行(課金を有効にすると生成上限が上がります)
2. **Vercelに設定**:
   - Vercelダッシュボード → 対象プロジェクト → **Settings → Environment Variables**
   - **Key**: `GEMINI_API_KEY` / **Value**: 取得したAPIキー
   - **Environments**: Production(必要ならPreviewも)にチェック → **Save**
3. 環境変数を追加/変更したら、**Deployments → 最新デプロイ → ⋯ → Redeploy** で再デプロイ(環境変数は再デプロイで反映されます)
4. (任意)モデルを変えたい場合は同様に `GEMINI_TEXT_MODEL` / `GEMINI_IMAGE_MODEL` / `GEMINI_TTS_MODEL` / `GEMINI_TTS_VOICE` を追加

> **タイムアウトについて**: Vercel Hobbyプランのサーバーレス関数は最大60秒です(`vercel.json` で設定済み)。挿絵・音声は並列生成しページ数を6に固定していますが、画像生成が遅い時間帯は60秒に近づくことがあります。頻発する場合はVercel Proへの変更、またはページ数(`api/generate-book.ts` の `PAGE_COUNT`)を減らして対処してください。

## iPadのホーム画面に追加する手順

1. iPadの **Safari** でデプロイしたURLを開く
2. 共有ボタン(□に↑)をタップ → **「ホーム画面に追加」**
3. 名前を確認して **追加**。以後は**ホーム画面のアイコンから起動**(フルスクリーン表示)

> **重要**: 絵本の**生成**はオンラインが必要です。生成済み絵本の閲覧は機内モードでも動きます。
> ストレージ永続化(`navigator.storage.persist()`)を起動時に要求します。長期間(7日以上)開かないとSafariの仕様でデータが消える可能性があるため、ときどき開いてください。

## 実機確認チェックリスト(iPad / iPhone)

自動E2Eテストは行わない方針のため、以下を実機で確認してください。

### 初回セットアップ
- [ ] `GEMINI_API_KEY` をVercelに設定し、再デプロイ済み
- [ ] Safariで開き、ホーム画面に追加できる / 起動時フルスクリーン
- [ ] 機内モードで起動しても、生成済み絵本の閲覧はできる(オフライン動作)

### 作成フロー(5歳と一緒に)
- [ ] アイコンを5つ、タップした順に選べる(番号バッジ表示・再タップで解除・←→で並び替え)
- [ ] 「えほんを つくる」で生成中アニメーション(アイコンがくるくる回る)が出る
- [ ] 数十秒待つと物語・挿絵・音声が生成され、できあがり確認画面に進む
- [ ] 生成に失敗したら「もういちど ためしてね」が出て再試行できる(**APIキー未設定だとここで失敗します**)
- [ ] 各ページで挿絵+物語文が表示され、「こえを きく」で生成音声が再生される
- [ ] 「🎤」で自分の声に録り直せる(**初回はマイク許可ダイアログ**)
- [ ] 効果音チップ(はくしゅ/どうぶつ/くるま/キラキラ/ラッパ)を選べる
- [ ] 表紙の絵を選べて、タイトルは生成タイトルが初期値で編集できる
- [ ] 「かんせい!」で保存され、お祝い画面→ホームに新しい絵本が出る

### 再生(2歳と一緒に)
- [ ] 絵本カードをタップすると全画面で開く
- [ ] ページを開くと音声(生成 or 録り直し)が自動再生される
- [ ] 音声が無いページは、よみあげ文があればWeb Speech TTS(日本語)で読まれる
- [ ] 画像をタップすると効果音が鳴る(**声と同時でも声は止まらない**)
- [ ] 左右の大きな◀▶でページ送り。連打しても暴走しない
- [ ] ページ送り時に本をめくるアニメーション(rotateY)が滑らかに再生される(iPhone実機)
- [ ] 右上の✕でホームに戻り、音が止まる / iPadの消音スイッチに注意

### 親モード
- [ ] ホーム右上隅を3秒長押しで親モードに入る
- [ ] タイトル・よみあげ文を編集できる / メタ表示が「✨ 生成音声」「🎤 録音あり」を区別
- [ ] ページ並び替え・表紙変更が再生画面に反映される
- [ ] 削除は確認が2回出て、絵本とページがすべて消える
